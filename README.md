# Templates PoC Temp
The idea of this repo is to define the first version of templates that will be used in PRs on Sortile repos. Templates are only available once merged to a repo's default branch, so it's not straightforward to test them in a production-ready repo. That said, this repo will serve as a place to refine templates in a safe environment before using them

This is a dummy modification to allow testing the defined PRs templates
